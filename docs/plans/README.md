# Plans

One file per task: `NN-task-name.md`, numbered in order. Each starts with a **Status**:

- **Proposed**: written, waiting for approval
- **WIP**: approved, being built
- **Done**: built, checks passing, committed (commit hashes listed in the plan)

Write one with `/plan-task <description>`, or approve a plan in plan mode (Claude saves it here). Ship it with `/ship-plan NN`.
